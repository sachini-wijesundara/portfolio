AI-Powered AR Mobile Cosmetics & Beauty Try-On App

A cutting-edge AR application enabling real-time cosmetic try-ons, AI hair/skin analysis, and product matching.

Project Overview

Developed as a Final Year Project, this AI-powered augmented reality beauty application enables users to virtually try cosmetic products in real time. Implemented live makeup rendering using native GPU rendering and Flutter UI. Integrated AI-based Makeup and hair colour try-on, hairstyle matcher, and skin/hair analysis features using trained TFLite models. Added e-commerce integration, product comparison tools, admin & delivery portals. Integrated Gemini API and OpenRouter APIs for AI-powered recommendations and assistance.

Key Features & Capabilities

01

Real-time makeup rendering using native GPU shader code.

02

TFLite models for real-time hair coloring, skin analysis, and hairstyle mapping.

03

Gemini API & OpenRouter integration for personalized AI beauty advice.

04

Complete e-commerce shop with comparing features, delivery tracking, and administrative portal.

The Challenge

Minimizing inference latency of ML models on lower-end mobile devices while rendering high-quality makeup shaders at 60fps.

The Solution

Quantized and optimized 8 TensorFlow Lite models to run under 150ms inference latency, and implemented custom mobile shaders to reduce CPU overhead.
